# Автодиспетчер — основа новой модели

Локальный прототип рабочего места диспетчера. Прежняя демонстрационная схема направлений, восемь модельных поездов, сценарии движения, история и отчёты удалены. Сейчас приложение показывает мировую железнодорожную карту и пустые разделы «Поезда» и «Журнал» — без выдуманных координат, скоростей и задержек.

## Запуск

Нужен Node.js 20 или новее. Запустите `start.cmd` либо выполните `npm start` в каталоге проекта. Сайт откроется по адресу `http://127.0.0.1:3000/`. Проверка: `npm test`.

Карта использует тайлы OpenStreetMap и OpenRailwayMap. Её можно перемещать по миру и масштабировать; кнопки 🌐 и KZ возвращают мировой обзор и Казахстан. Список слоёв позволяет смотреть пути, сигналы, допустимые скорости, электрификацию и ширину колеи. При отсутствии сети остаётся упрощённая локальная карта мира. Полнота путей и станций зависит от данных OpenStreetMap.

## Новые данные поездов

`GET /api/state` сейчас возвращает пустые массивы `trains`, `incidents` и `events` с `status: "empty"`. Источник поездных данных пока не выбран. Новую модель следует строить от проверенного источника, с идентификаторами поездов, временем обновления и точной привязкой к путям. Правила триажа Level 1–3 оставлены в `server/incidents.js` и доступны как справочник через `GET /api/incident-types`; активных оценок нет.

Локальный справочник Казахстана: `data/stations-kz.json` содержит 645 станций, 154 остановочных пункта и 259 боковых путей из выгрузки GeoNames от 01.10.2026. Ещё 54 точки, отсутствующие в GeoNames ближе 500 м, находятся в `data/stations-kz-osm.json` и взяты из [railroutes](https://github.com/mayurrawte/railroutes) на основе OpenStreetMap ([ODbL 1.0](https://opendatacommons.org/licenses/odbl/)). Кокшетау-1 добавлена по [Wikidata](https://www.wikidata.org/wiki/Q102047169) (CC0). Общий каталог содержит 1113 железнодорожных объектов, включая 700 станций. Поиск `GET /api/stations?q=...` сначала проверяет локальный каталог и понимает русские варианты названий; для остальных стран пытается обратиться к OpenRailwayMap API. Полный каталог для точек карты: `GET /api/stations/kz`. На карте локальные точки появляются с масштаба 8 и отключаются отдельным переключателем. Описание API: `GET /api/openapi.json`.

Исходный архив `data/geonames-KZ.zip` взят с [GeoNames](https://download.geonames.org/export/dump/KZ.zip), лицензия [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Для пересборки файла запустите `./scripts/import-geonames.ps1` в PowerShell. Записи отбираются по кодам `RSTN`, `RSTP`, `RSD`; название выбирается из русскоязычных вариантов, где они есть. Это полный набор **железнодорожных объектов в данной выгрузке GeoNames**, а не гарантированно полный или актуальный эксплуатационный реестр КТЖ. Коды ЕСР в этом источнике отсутствуют. Координаты Матая уточнены по [Wikidata](https://www.wikidata.org/wiki/Q98908403).

## ИИ-помощник

Помощник отвечает о карте и текущем пустом состоянии. При наличии `OPENAI_API_KEY` в `.env` он использует OpenAI API; без ключа работает локальный ответ. Файл `.env` исключён из Git. Помощник не выдаёт вымышленные данные о поездах и не управляет движением.

Ранее подготовленные исследования сохранены отдельно: `research-akmola.md`, `research-live-tracking.md`, `research-innovations.md`. Они не загружаются в работающий интерфейс.
